DataGrip

Bis hierhin haben Sie SQL im Browser geschrieben – im SQL-Editor von Supabase oder in der Konsole dieser Seiten. Für ernsthafte Arbeit fehlt dort einiges: Code Completion aus dem Schema, ein Diagramm der Beziehungen, eine Abfragehistorie und eine kontrollierte Ausführung. Genau das leistet ein Datenbankwerkzeug. Der wichtigste Schalter darin ist unscheinbar und trägt drei Buchstaben – er entscheidet, ob eine Änderung im Data Editor sofort und unwiderruflich gilt. Up to here you have written SQL in the browser – in Supabase's SQL editor or in this site's console. For serious work a few things are missing there: completion from the schema, a diagram of the relationships, a query history and controlled execution. That is exactly what a database tool provides. The most important switch in it is inconspicuous and carries three letters – it decides whether a change in the data grid applies immediately and irreversibly.

Ein Werkzeug, das das Schema kenntA tool that knows the schema

DataGrip ist die auf Datenbanken ausgerichtete Entwicklungsumgebung von JetBrains. Sie liest das Schema der verbundenen Datenbank ein – man nennt das Introspektion – und nutzt es für Code Completion, Sprungmarken zwischen Tabellen und Warnungen, bevor eine Abfrage überhaupt läuft. Wer einen Spaltennamen falsch schreibt, sieht es hier vor dem Ausführen und nicht danach in einer Fehlermeldung. DataGrip is JetBrains' database-oriented development environment. It reads the connected database's schema – this is called introspection – and uses it for completion, jumping between tables and warnings before a query even runs. Whoever misspells a column name sees it here before executing and not afterwards in an error message.

Das erklärt auch die wichtigste Bedienhürde, die weiter unten kommt: Introspiziert wird nur, was als sichtbar geschaltet ist. Eine Tabelle, die existiert, aber nicht ausgewählt wurde, taucht im Baum nicht auf und ist der Code Completion unbekannt – und dann sucht man den Fehler in der Abfrage, statt in einer Anzeigeeinstellung. That also explains the most important operating hurdle, which comes further down: only what is set to visible gets introspected. A table that exists but was not selected does not appear in the tree and is unknown to the completion – and then you look for the bug in the query rather than in a display setting.

Hinweis. Bei den in dieser Lernumgebung gezeigten Tools handelt es sich um eine Auswahl – diese ist weder als Empfehlung noch als Werbung zu verstehen. Kostenlose Alternativen auf derselben Ebene: DBeaver Community (Apache 2.0, breite Systemabdeckung), pgAdmin 4 (quelloffen, nur PostgreSQL) und VS Code mit einer SQL-Erweiterung – Microsoft verweist seit der Einstellung von Azure Data Studio im Februar 2026 ausdrücklich auf diesen Weg. Alles, was Sie hier über Transaktionsmodus und Schema-Sichtbarkeit lernen, gilt dort ebenso. Note. The tools shown in this learning environment are a selection – it is meant neither as a recommendation nor as advertising. Free alternatives on the same layer: DBeaver Community (Apache 2.0, broad system coverage), pgAdmin 4 (open source, PostgreSQL only) and VS Code with a SQL extension – since the retirement of Azure Data Studio in February 2026 Microsoft expressly points to this route. Everything you learn here about transaction mode and schema visibility applies there too.

Data Source anlegenCreate a data source

Eine Data Source ist eine gespeicherte Verbindung: System, Adresse, Zugangsdaten, Treiber. Seit Version 2026.2 sind fünf Treiber mitgeliefert – darunter PostgreSQL –, sodass der frühere Zwischenschritt „fehlende Treiberdateien herunterladen“ für diesen Kurs entfällt. A data source is a stored connection: system, address, credentials, driver. Since version 2026.2 five drivers are bundled – PostgreSQL among them – so the former intermediate step “download missing driver files” does not apply to this course.

Das Passwort gehört nicht in das URL-FeldThe password does not belong in the URL field

Der Dialog hat ein Feld URL und ein Feld Password. Wer die vollständige Connection String samt Passwort in das URL-Feld einträgt – naheliegend, weil Supabase sie genau so anzeigt –, hat das Passwort danach im Klartext in den Protokolldateien und Konfigurationsdateien der Umgebung. Passwort ins Passwortfeld, und in der URL steht es nicht. The dialogue has a URL field and a Password field. Whoever enters the full connection string including the password into the URL field – tempting, because Supabase displays it exactly like that – then has the password in plain text in the environment's log and configuration files. Password into the password field, and it is not in the URL.

Für Rechnerpools mit wechselnden Nutzern: Settings → System Settings → Passwords auf Do not save – dann fragt DataGrip jedes Mal neu. Die Alternativen sind der Schlüsselbund des Systems oder eine KeePass-Datei mit eigenem Hauptpasswort. For computer pools with changing users: Settings → System Settings → Passwords to Do not save – then DataGrip asks every time. The alternatives are the system keychain or a KeePass file with its own master password.

Was in der Data Source für die Datei anders ist: Es gibt kein Schema-Register (Lab 06: eine Datei ist ein Schema), Tx:Manual funktioniert wie bei Postgres – nur dass eine zweite Verbindung auf dieselbe Datei mit database is locked antwortet, solange die erste eine offene Transaktion hält. Genau deshalb steht Read-only bei der zweiten Data Source nicht nur zur Zierde. What differs in the file data source: there is no schema register (lab 06: one file is one schema), Tx:Manual works as with Postgres – except that a second connection to the same file answers database is locked as long as the first holds an open transaction. That is precisely why Read-only on the second data source is not just decoration.

Sichtbare SchemataVisible schemas

Neben dem Namen der Data Source steht ein Verweis wie 1 of 5 – er sagt, wie viele Schemata von wie vielen eingelesen werden. Was nicht ausgewählt ist, erscheint nicht im Baum und ist der Code Completion unbekannt. Die Tabelle existiert, das Werkzeug sieht sie nur nicht an. Beside the data source's name stands a link like 1 of 5 – it says how many schemas of how many are being read. What is not selected does not appear in the tree and is unknown to the completion. The table exists, the tool merely does not look at it.

Bei Supabase ist das besonders auffällig: Neben public gibt es Schemata für Authentifizierung, Dateiablage und interne Verwaltung. Sinnvoll ist, public sichtbar zu schalten und die übrigen weggeschaltet zu lassen – dann bleibt der Baum lesbar und die Code Completion schlägt keine internen Tabellen vor. With Supabase this is particularly noticeable: besides public there are schemas for authentication, file storage and internal administration. It makes sense to set public visible and leave the rest switched off – then the tree stays readable and the completion does not suggest internal tables.

Die KonsoleThe console

Eine Query Console ist ein Editor, der an eine Data Source gebunden ist. F4 auf der markierten Data Source öffnet die Standardkonsole, Strg+Shift+Q eine neue. Der entscheidende Handgriff ist die Ausführung – und die verhält sich anders, als man erwartet. A query console is an editor bound to a data source. F4 on the selected data source opens the default console, Strg+Shift+Q a new one. The decisive action is execution – and it behaves differently from what you expect.

Stehen mehrere Anweisungen in der Konsole, erscheint bei Strg+Enter eine Auswahlliste: die Anweisung unter dem Cursor – oder run all statements. Diese Liste wird gern weggeklickt, und dann läuft ein ganzes Skript, von dem nur eine Zeile gemeint war. Zwei Gewohnheiten, die das verhindern: die Liste lesen, und für eine einzelne Ausführung den Text vorher markieren – dann wird genau die Markierung ausgeführt, ohne Rückfrage. If several statements sit in the console, Strg+Enter brings up a picker: the statement under the cursor – or run all statements. That picker gets clicked away, and then a whole script runs when only one line was meant. Two habits that prevent it: read the picker, and for a single execution select the text beforehand – then exactly the selection runs, without a question.

Der Schalter, auf den es ankommtThe switch that matters

In der Werkzeugleiste der Konsole und des Data Editors steht ein Auswahlfeld mit zwei Buchstaben und einem Doppelpunkt: Tx:. Es entscheidet, was mit einer Änderung passiert, die Sie im Data Editor vornehmen – und es ist der Grund, warum ein unbeabsichtigter Klick in einer Zelle eine Produktionsdatenbank ändern kann. In the toolbar of the console and the data grid sits a dropdown with two letters and a colon: Tx:. It decides what happens to a change you make in the data grid – and it is the reason an unintended click in a cell can change a production database.

Drei Gewohnheiten, die eine Datenbank rettenThree habits that save a database

  1. Tx:Manual als Voreinstellung – je Data Source im Reiter Options. Dann ist jede Änderung im Data Editor zunächst nur abgeschickt, nicht committet. Tx:Manual as the default – per data source in the Options tab. Then every change in the data editor is initially only submitted, not committed.
  2. Preview Pending Changes vor jedem Submit – es zeigt das UPDATE, das DataGrip erzeugen würde. Zwei Sekunden Lesen, und ein fehlendes WHERE fällt auf, bevor es wirkt. Preview Pending Changes before every Submit – it shows the UPDATE DataGrip would generate. Two seconds of reading, and a missing WHERE is noticed before it takes effect.
  3. Read-only für alles, was Sie nicht ändern dürfen – im Reiter Options der Data Source. Für eine Produktionsdatenbank ist das keine Vorsicht, sondern Pflicht: Ein Haken verhindert die ganze Klasse von Unfällen. Read-only for everything you may not change – in the data source's Options tab. For a production database that is not caution but duty: one checkbox prevents the whole class of accidents.

Und die Regel, die unabhängig vom Werkzeug gilt: Ein UPDATE oder DELETE wird zuerst als SELECT mit demselben WHERE geschrieben. Die Trefferzahl notieren, dann umschreiben. Wer das tut, hat noch nie versehentlich eine ganze Tabelle überschrieben – dieselbe Disziplin wie das ls vor dem rm in Lab 01. And the rule that applies regardless of the tool: an UPDATE or DELETE is first written as a SELECT with the same WHERE. Note the row count, then rewrite it. Whoever does that has never accidentally overwritten a whole table – the same discipline as the ls before the rm in lab 01.

Finden und verstehenFinding and understanding

Vor einer Auswertung steht die Frage, wie die Daten zusammenhängen. Ein Schemadiagramm beantwortet sie in zehn Sekunden – und entspricht dem, was DABA als Entity-Relationship-Modell behandelt. Before an analysis comes the question of how the data hangs together. A schema diagram answers it in ten seconds – and corresponds to what DABA treats as the entity-relationship model.

Große ErgebnismengenLarge result sets

Die Seitengröße ist voreingestellt begrenzt – zu finden unter Settings → Tools → Database → Data Views. Nimmt man den Haken weg und fragt zwei Millionen Zeilen ab, friert die Umgebung ein. In der Abfrage gehört ein LIMIT dazu, und für Massendaten wird exportiert statt angezeigt. The page size is limited by default – found under Settings → Tools → Database → Data Views. Remove the checkbox and query two million rows, and the environment freezes. A LIMIT belongs in the query, and for bulk data you export rather than display.

SSL

Im Reiter SSH/SSL: Use SSL einschalten, Verifikationsmodus wählen. Bei Supabase ist Verschlüsselung Pflicht und im Connection String enthalten. Bei einer Hochschul-Datenbank lohnt der Modus Verify CA mit hinterlegtem Zertifikat – und ein SSH-Tunnel statt eines offenen Ports. In the SSH/SSL tab: enable Use SSL, choose a verification mode. With Supabase encryption is mandatory and contained in the connection string. With a university database the Verify CA mode with a stored certificate is worth using – and an SSH tunnel instead of an open port.
